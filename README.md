# إدارة مدرستي — Android (Kotlin + Compose + Room + SQLCipher)

## بناء ملف APK عبر GitHub (دون تثبيت أي برنامج)
1. أنشئ مستودعاً جديداً على GitHub (Private مفضّل، فالتطبيق خاص بمدرستك).
2. فكّ ضغط الملف ثم ارفع **محتويات** المجلد (وليس المجلد نفسه) إلى جذر المستودع: `app` و`gradle` و`build.gradle.kts` و`settings.gradle.kts` و`gradle.properties` وبقية الملفات.
3. تأكد أن المسار `.github/workflows/build-apk.yml` موجود. إن لم يظهر بعد الرفع (المجلدات المخفية تُتخطّى أحياناً) فأنشئه من GitHub: Add file ← Create new file، واكتب المسار كاملاً، والصق محتوى الملف المرفق `build-apk.yml`.
4. بعد الرفع يبدأ البناء تلقائياً. تابعه من تبويب **Actions** (يستغرق 5–10 دقائق في المرة الأولى).
5. عند النجاح افتح التشغيل ← **Artifacts** ← حمّل `IdaratMadrasati-debug-apk`، فك الضغط، وثبّت `app-debug.apk` على الهاتف (اسمح بالتثبيت من مصدر غير معروف).
6. **عند الفشل**: حمّل الأرتيفاكت `build-logs` وأرسل لي محتوى `build.log` (أو الأسطر التي تبدأ بـ `e:`) لأصلح الأخطاء.

## نسخة موقّعة للنشر (اختياري)
أنشئ مفتاح توقيع مرة واحدة (`keytool -genkey -v -keystore release.jks -alias school -keyalg RSA -keysize 2048 -validity 10000`)، ثم أضف في المستودع: Settings ← Secrets and variables ← Actions أربعة أسرار: `KEYSTORE_BASE64` (محتوى الملف بعد تحويله base64) و`KEYSTORE_PASSWORD` و`KEY_ALIAS` و`KEY_PASSWORD`. عندها يُنتج البناء أيضاً `IdaratMadrasati-release-apk`. **احتفظ بملف المفتاح وكلمته في مكان آمن: ضياعهما يمنع تحديث التطبيق لاحقاً.**
